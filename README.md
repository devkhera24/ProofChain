# ProofChain

A collaborative research agent that links every claim to verified, quoted evidence from your sources and
recommends real, verified papers to fill the gaps.

**Status:** in development

## Live

- App: https://proof-chain-virid.vercel.app
- API: https://proofchain-api-quf3.onrender.com/api/health (free tier sleeps when idle; first request can take ~60s)

## Local development

```bash
npm run install:all
npm run dev
```

(Full setup, deployment and environment documentation will be completed in Step 30.)
